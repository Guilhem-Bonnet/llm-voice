# Bienvenue dans LLM Voice

Ceci est un document d'exemple, livré avec l'extension pour que vous puissiez
entendre une lecture sans avoir à ouvrir l'un de vos propres fichiers.

Pendant la lecture, le segment en cours est surligné directement dans
l'éditeur, et les boutons de lecture (précédent, lecture/pause, suivant,
arrêt) apparaissent dans le mini-player, en bas de l'écran.

## Lire une section précise

Chaque titre Markdown affiche un lien **« ▶ Lire cette section »**
au-dessus de lui : cliquez dessus pour ne lire que ce qui suit, sans repartir
du début du document.

## Et ensuite ?

Essayez de changer de profil de lecture (**LLM Voice: Select Profile**), ou
copiez un texte quelconque dans le presse-papiers et lancez
**LLM Voice: Speak Clipboard**. Bonne écoute.
