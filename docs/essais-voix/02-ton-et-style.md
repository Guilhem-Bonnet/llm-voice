# Ton et style

Le même message écrit de plusieurs façons. Pocket TTS n'a pas de réglage de ton : seule l'écriture du texte varie ici.

@neutre: La mise à jour est terminée. Le serveur a redémarré et les tests sont passés. Il reste une erreur à corriger dans le cache.
@chaleureux: Bonne nouvelle, la mise à jour est terminée ! Le serveur a bien redémarré, et les tests sont passés. Il nous reste juste une petite erreur à corriger dans le cache.
@enthousiaste: C'est fait ! La mise à jour est terminée ! Le serveur a redémarré, tous les tests sont passés ! Allez, plus qu'une erreur à corriger dans le cache !
@grave: La mise à jour est terminée. Le serveur a redémarré. Les tests sont passés. Mais attention : une erreur subsiste dans le cache, et elle ne doit pas être ignorée.
@pedagogue: Voyons où nous en sommes. D'abord, la mise à jour est terminée. Ensuite, le serveur a redémarré, et les tests sont passés. Enfin, regardons cette dernière erreur, dans le cache.
@confidentiel: Entre nous… la mise à jour est terminée. Le serveur a redémarré… les tests sont passés. Il reste seulement, tout petit, un souci dans le cache.
@interrogatif: La mise à jour est terminée, n'est-ce pas ? Le serveur a-t-il redémarré ? Les tests sont-ils passés ? Et cette erreur dans le cache, que fait-on ?
@pauses: La mise à jour est terminée… Le serveur a redémarré, oui… Les tests sont passés. Et maintenant — il reste une erreur à corriger, dans le cache.
